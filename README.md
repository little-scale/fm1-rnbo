# fm1-rnbo

RNBO instruments, loadable DSP patches, and a custom RNBO Player for FM1.

The project runs compiled RNBO instruments on the FM1 through a permanent
player, with MIDI input, eight parameter controls, audio meters and persistent
patch storage. FM4Echo combines four-voice FM synthesis with a shared stereo
echo. A three-patch bank, PRESETS selection and browser uploader are in
development; their latest changes have passed local checks and await device
validation.

This repository currently contains project documentation and licensing files.
The implementation has not yet been imported.
